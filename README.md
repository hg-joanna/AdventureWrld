# Adventure World

## Overview

Adventure World is a Python-based adventure game inspired by the classic Wumpus World environment. Players navigate a grid-based world while avoiding hidden dangers, collecting gold, and using environmental clues to make strategic decisions.

## Features

- Grid-based exploration
- Multiple selectable grid sizes
- Hidden pits and gold placement
- Environmental clues (breeze and glitter)
- Game-over and win conditions

## Technologies

- Python
- SWI-Prolog

## How to Run

### Prerequisites

Ensure the following software is installed:

- Python
- SWI-Prolog

### Run the Game

Open a terminal in the project directory and execute:

```bash
python FINALmain.py
```

Choose a grid size when prompted, then begin exploring the world.

## Gameplay

- **Breeze** indicates that one or more adjacent tiles contain a pit.
- Falling into a **pit** immediately ends the game.
- **Glitter** indicates that gold is present on the current tile.
- Collect gold while carefully navigating the environment using the available clues.
